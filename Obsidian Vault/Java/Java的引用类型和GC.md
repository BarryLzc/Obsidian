# 引用类型
## 强引用
这是最常见的引用方式。只要强引用存在，垃圾回收器**永远不会**回收掉被引用的对象。

- **写法：** `Object obj = new Object();`
    
- **特点：** 宁愿抛出 `OutOfMemoryError` (OOM) 导致程序崩溃，也不会回收这些对象。
    
- **如何回收：** 将引用显式赋值为 `null`，或者超出对象的生命周期范围。

## 软引用
软引用用于描述一些**有用但非必需**的对象。

- **回收时机：** 只有在**内存不足**（即将发生 OOM）时，垃圾回收器才会回收这些对象。如果内存充足，它们可以继续存活。
    
- **应用场景：** 非常适合做**内存敏感的缓存**（比如网页缓存、图片缓存）。
    
- **写法：**
    Java
```
  SoftReference<String> softRef = new SoftReference<>(new String("Hello"));
```

## 弱引用
弱引用的强度比软引用更低。

- **回收时机：** 只要垃圾回收器开始扫描内存区域，**无论当前内存是否足够**，都会回收掉只被弱引用关联的对象。
    
- **应用场景：** 防止内存泄漏。常用于 `ThreadLocal` 的内部实现以及 `WeakHashMap`。
    
- **写法：**
    Java
```
	WeakReference<String> weakRef = new WeakReference<>(new String("Hello"));
```
ThreadLocal使用的是弱引用：[[ThreadLocal]]
## 虚引用
这是最弱的一种引用，它甚至无法通过引用获取到对象的实例。

- **回收时机：** 随时可能被回收。
    
- **作用：** 它的唯一目的是在对象**被回收时收到一个系统通知**。它必须和引用队列（ReferenceQueue）联合使用，用来跟踪对象被垃圾回收的活动，通常用于管理堆外内存。
    
- **写法：**
    Java
```
   PhantomReference<String> phantomRef = new PhantomReference<>(new String("Hello"), queue);
 ```

## 核心对比表

|**引用类型**|**回收时机**|**生存时间**|**常见应用场景**|
|---|---|---|---|
|**强引用**|永远不回收（除非不可达）|只要引用在，就一直存活|普通对象创建|
|**软引用**|内存不足时回收|内存不足前存活|缓存（如图片缓存）|
|**弱引用**|GC 扫描到即回收|存活到下一次 GC 前|解决内存泄漏（如 ThreadLocal）|
|**虚引用**|随时被回收|极短（无法获取实例）|管理堆外内存、回收通知|
