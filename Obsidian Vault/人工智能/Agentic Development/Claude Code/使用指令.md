## 安装
### 推荐方式
```
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# macOs（Homebrew）
brew install claude-code
# 手动更新（不会自动更新）
brew upgrade claude-code
```
### npm（需要 Node.js 18+）
```
npm install -g @anthropic-ai/claude-code
```

## 登录 / 认证
```
# 启动交互式会话（首次会自动引导登录）
claude

# 命令行直接登录
claude auth login

# 查看当前登录状态（账户、套餐、有效期）
claude auth status

# 登出
claude auth logout

# 会话中切换账户
/login
```

## 版本确认
```
# Homebrew
brew upgrade claude-code

# npm
npm update -g @anthropic-ai/claude-code

# WinGet
winget upgrade Anthropic.ClaudeCode
```
