
虽然名字里带着“回归”二字，但它其实是用来预测**概率**并进行**二分类**（例如：是/否、赢/输、垃圾邮件/正常邮件）的。

---

### 1. 它是如何工作的？

逻辑回归的核心思想是在线性回归的基础上，套用了一个非线性的激活函数——**Sigmoid 函数**。

- **线性部分：** 它先计算一个线性加权和（就像普通回归一样），**但不能用线性回归的y = wx+b的公式，因为普通线性函数的输出值不是概率（0-1之间）**。
- **激活部分：** 将线性结果输入到 Sigmoid 函数中，将数值压缩到 **0 到 1** 之间。所以逻辑回归使用[[交叉商对数]]作为它的损失函数

当输出值接近 1 时，代表事件发生的可能性很高；接近 0 时，代表可能性很低。通常我们会设定一个阈值（比如 0.5），超过这个值就划分为“类别 A”，低于它就划分为“类别 B”。
例如，当我们将阈值设为 **0.5** 时，逻辑回归的分类逻辑可以进一步对应到线性部分：
- 当 $p \ge 0.5$ 时，意味着 $\sigma(wx+b) \ge 0.5$，这等价于线性部分 **$wx+b \ge 0$**。**整体为真**
- 当 $p < 0.5$ 时，意味着 $\sigma(wx+b) < 0.5$，这等价于线性部分 **$wx+b < 0$**。**整体为假**
### 2. 核心数学公式
逻辑回归的预测模型可以表示为：

$$y = \frac{1}{1 + e^{-z}}$$

其中，$z$ 是输入特征的线性组合：

$$z = w_0 + w_1x_1 + w_2x_2 + \dots + w_nx_n$$

- $y$ 是预测的概率值。
    
- $e$ 是自然对数的底数。
    
- $w$ 是模型学习到的权重参数。

#### 2.1 线性部分：$z = wx + b$

这部分负责**提取信息**。

- **$x$ (输入)**：你提供给模型的数据（例如：房屋面积、患者血压）。
    
- **$w$ (权重, Weights)**：模型学习到的“重要程度”。$w$ 越大，说明这个特征对结果影响越大。
    
- **$b$ (偏置, Bias)**：模型的“基础分”，用来调整模型的灵活性。
    

这一步计算出来的结果 $z$ 是一个可以在负无穷到正无穷之间波动的数值。

#### 2.2 激活函数：$\sigma$ (Sigmoid)

这部分负责**映射概率**。

由于 $z$ 的范围太广，直接用来做分类很不方便。我们使用 **Sigmoid 函数**（符号为 $\sigma$）来做一个“挤压”操作：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

- 如果 $z$ 是一个很大的正数，$\sigma(z)$ 会无限接近 **1**。
    
- 如果 $z$ 是一个很大的负数，$\sigma(z)$ 会无限接近 **0**。
    
- 如果 $z = 0$，则 $\sigma(z) = 0.5$。
#### 2.3 整体含义：$\sigma(wx + b)$

当你把它们合在一起时，这个公式的意思是：

> **“根据输入的特征 $x$，通过权重 $w$ 和偏置 $b$ 计算出一个总分，然后将这个分数压缩到 0 到 1 之间，作为事件发生的『概率』。”**

### 3. 为什么不直接用线性回归做分类？

这是一个很棒的问题！主要原因有两点：

1. **取值范围：** 线性回归的输出可以是负无穷到正无穷，而概率必须在 0 和 1 之间。
    
2. **鲁棒性：** 线性回归对异常值非常敏感，一个极端的离群点可能会大幅拉动回归线，导致分类边界严重偏移。逻辑回归通过 Sigmoid 函数的“S型曲线”有效地解决了这个问题。
### 4. 逻辑回归的优缺点

|**优点**|**缺点**|
|---|---|
|**计算高效**：速度快，占用内存少。|**拟合能力有限**：很难处理复杂的非线性关系。|
|**可解释性强**：权重的正负能直接反映特征对结果的影响。|**依赖特征工程**：通常需要人工处理特征间的交互。|
|**输出概率**：不仅给出结论，还给出置信度。|**容易欠拟合**：在复杂数据集上表现不如神经网络或随机森林。|

### 5. 常见的应用场景

- **金融领域**：预测贷款申请人是否会违约（违约/不违约）。
    
- **医疗领域**：根据体检指标判断病人是否患有某种疾病。
    
- **营销领域**：预测用户是否会点击广告（点击/不点击）。
