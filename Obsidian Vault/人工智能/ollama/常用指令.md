# 一、基础认知（先统一概念）

👉 Ollama 本质是：

本地模型运行时 + HTTP服务 + 模型管理器

👉 所以命令分三类：

1. **服务管理**
    
2. **模型管理**
    
3. **模型使用**
    

---

# 二、服务相关（最重要）

## 1. 启动服务

ollama serve

👉 默认：

http://localhost:11434

---

## 2. 指定端口启动

OLLAMA_HOST=0.0.0.0:11435 ollama serve

---

## 3. 检查服务是否正常

curl http://localhost:11434

---

# 三、模型管理（你每天都会用）

## 1. 查看本地模型

ollama list

---

## 2. 下载模型（必须）

ollama pull llama3  
ollama pull qwen3.5:9b  
ollama pull nomic-embed-text

---

## 3. 删除模型

ollama rm llama3

---

## 4. 查看模型信息

ollama show llama3

---

# 四、模型运行（核心）

## 1. 启动对话（最常用）

ollama run llama3

👉 进入聊天模式

---

## 2. 一次性执行（非交互）

ollama run llama3 "解释一下RAG"

---

## ⚠️ 注意

❌ ollama run nomic-embed-text

👉 embedding 模型不能 run

---

# 五、运行状态（调试必备）

## 1. 查看当前运行模型

ollama ps

---

## 2. 停止模型

ollama stop llama3

---

# 🌐 六、API 调用（你写 Go 必用）

## 1. Chat（大模型）

curl http://localhost:11434/api/chat -d '{  
  "model": "qwen3.5:9b",  
  "messages": [  
    { "role": "user", "content": "你好" }  
  ]  
}'

---

##  2. Embedding

curl http://localhost:11434/api/embeddings -d '{  
  "model": "nomic-embed-text",  
  "prompt": "Shopline 是什么"  
}'

---

## 3. Generate（补充）

curl http://localhost:11434/api/generate -d '{  
  "model": "llama3",  
  "prompt": "写一段介绍"  
}'

👉 和 chat 类似，但更简单

---

# 七、高级用法（你后面会用到）

## ✅ 1. keep_alive（防止模型卸载）

{  
  "model": "llama3",  
  "keep_alive": "10m"  
}

---

## ✅ 2. 批量 embedding（提速）

{  
  "model": "nomic-embed-text",  
  "prompt": ["文本1", "文本2"]  
}

---

## ✅ 3. 自定义模型（Modelfile）

ollama create my-model -f Modelfile

---

# 八、完整工作流（你现在的RAG）

完成使用链路：

1. ollama serve  
2. ollama pull 模型  
3. embedding → /api/embeddings  
4. Milvus 检索  
5. chat → /api/chat

---

# 九、常见坑总结（帮你避雷）

## ❌ 1. 以为模型要“手动启动”

错：需要 start  
对：调用自动加载

---

## ❌ 2. embedding 用错接口

❌ /api/chat  
✅ /api/embeddings

---

## ❌ 3. 每个模型一个端口

❌ 错  
✅ 所有模型共享11434

---

## ❌ 4. 模型名写错

一定要以这个为准：ollama list
