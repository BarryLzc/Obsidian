JSONPath 是一种用于查询 JSON 结构的表达式语言，类似于 SQL 对数据库的查询方式。它允许你以一种简洁的方式提取 JSON 数据的特定部分。

### **工作原理**

JSONPath 的工作方式可以分为以下几个步骤：

1. **解析 JSON 数据**  
    JSONPath 解析器会解析 JSON 数据并将其转换为内部数据结构（通常是树状结构）。
    
2. **解析 JSONPath 表达式**  
    JSONPath 解析器会分析用户提供的 JSONPath 表达式，并确定查询路径。
    
3. **遍历 JSON 结构并匹配节点**  
    JSONPath 解析器按照表达式指定的路径，遍历 JSON 结构，并筛选出符合条件的节点。
    
4. **返回匹配结果**  
    最终，解析器会将匹配到的数据以数组或对象的形式返回。
