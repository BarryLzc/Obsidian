5. IPV4和IPV6的区别
	- IPV4由4组10进制的数字维护，共32位（每组十进制由8位2进制表示），大约43亿IP地址。
	- IPV6由4组16进制的数字维护，共128位（每组十六位进制由16位2进制表示），约等于无限大。
6. DNS查询IP的方式：迭代查询和递归查询
	- 迭代查询：给的是线索，立即返回，没有进一步探索。例如，本地服务器代理查询权威、TLD和根服务器，**迭代查询则分散了（根域名服务器）查询负载，提高了安全性，但可能会降低解析速度和用户体验（需要多次请求）**。
	- 递归查询：给的答案，没有立即返回，有进一步探索（客户端向本地服务器提交请求用的就是递归请求，因为直接返回答案）。**递归查询提供了更快的解析速度和更好的用户体验，但可能会增加根域名服务器负载和安全风险****。
	- 无论是递归查询还是迭代查询，DNS的第一次解析流程都是：本地电脑 -> 本地DNS -> 根DNS -> TLD DNS -> 权威DNS -> 本地DNS -> 本地电脑（操作系统、浏览器写入缓存）

8. DNS各层级的意义
- **根域名服务器 ≠ 域名解析的兜底**  
- 根 / TLD DNS 没有缓存 IP
- 权威 DNS = 保存域名记录、对域名解析结果拥有最终决定权的 DNS 服务器，**所以权威 DNS 是 DNS 链路中唯一保存“域名 → IP”映射的节点，没有任何上级可以替代它**。
- **权威 DNS 挂了 = 这个域名在互联网上“逻辑上不存在”**
- 权威DNS不转发、不猜测、不缓存，是域名所有者配置的。
