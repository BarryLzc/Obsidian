HTTP 2（2015年发布）的核心目标是解决 HTTP 1.1 的**效率低**和**头部冗余**问题，基于谷歌的 SPDY 协议开发。

- **多路复用 (Multiplexing) —— 彻底告别队头阻塞：** 在 HTTP 1.1 中，即使连接是持久的，请求也必须排队发送（前面的卡住，后面全等）。HTTP 2 将请求拆分为细小的“帧”，在同一个连接上交错传输。多个请求可以并行，互不干扰。
    
- **二进制分层 (Binary Framing)：** HTTP 1.1 是纯文本协议，解析起来慢。HTTP 2 将所有信息打包成二进制格式，机器读取速度更快，出错率更低。
    
- **头部压缩 (HPACK)：** HTTP 请求头中有很多重复信息（如 User-Agent、Cookie）。HTTP 2 在客户端和服务器维护一张“索引表”，相同的头只传索引号，大幅减少了数据量。
    
- **服务器推送 (Server Push)：** 服务器可以在客户端还没请求时，主动把 CSS、JS 等资源推送到客户端缓存里，进一步缩短网页加载时间。
