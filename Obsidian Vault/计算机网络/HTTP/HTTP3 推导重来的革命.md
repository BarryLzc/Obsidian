尽管 HTTP 2 很强，但它建立在 TCP 协议之上。TCP 的“队头阻塞”是操作系统内核层面的，HTTP 2 无法逾越。于是 HTTP 3（2020年起推广）索性**放弃了 TCP，改用基于 UDP 的 QUIC 协议**。

- **QUIC 协议：解决 TCP 队头阻塞：** 在 HTTP 2 中，如果 TCP 丢了一个包，整个连接都会停下来等这个包重传。而 HTTP 3 (QUIC) 实现了真正的流级别隔离，一个流丢包，不影响其他流的传输。
    
- **极速建连 (0-RTT / 1-RTT)：** TCP + TLS 通常需要 2-3 次握手才能开始传数据。HTTP 3 将传输层握手和加密层（TLS 1.3）合并，最快可以在 0 次往返内就开始发送数据，网页几乎是“秒开”。
    
- **连接迁移 (Connection Migration)：** TCP 连接由 IP 和端口绑定。当你从 Wi-Fi 切换到 5G 时，IP 变了，TCP 就会断开重连。HTTP 3 使用 **Connection ID** 来标识连接，即使你的网络环境变了，只要 ID 不变，数据传输就不会中断。
