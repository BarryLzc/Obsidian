1. TCP协议（使用[[虚通路]]、可靠传播、支持顺序、信息量大、网络场景不良好等场景）包含：FTP（File Transfer Protocol）、 HTTP、Telnet（windows系统中可以用它来发送文件，但是用户名和密码也是明文的并不安全）、SMTP（Simple Mail Transfer Protocol）
2. UCP协议（不使用虚通路、数据量小且传输快速、支持广播、客户端重复查询）包含：[[DHCP（动态主机配置协议）]]（Dynamic Host Configuration Protocl，DHCP 用于**自动分配 IP 地址**和其他网络配置（如子网掩码、网关和 DNS 服务器等）给网络中的计算机和设备，从而简化网络管理，避免手动配置每个设备的网络参数。）、TFTP（Trivial File Protocol）、SNMP（Simple Network Management Protocol）、SMTP（Simple Mail Transfer Protocol，支持25（服务器间传输），587（TLS 加密），465（SSL 加密）传输）、DNS（Domain Name System）
3. IP协议（网络层传输协议）：ICMP（Internet Control Message Protocol互联网控制消息协议，主要用于网络诊断和错误报告、例如Ping命令）、IGMP（Internet Group Management Protocol，多播是一种向一组设备而非单一设备或所有设备发送数据的通信方式。它适用于广播电视、视频会议、网络广播等应用场景，没有安全机制，一些现代网络提供了IGMP的认证机制R）、ARP（Address Resolution Protocol，从IP找MAC地址）、RARP（Reverse Address Resolution Protocol，从MAC地址找IP地址，从MAC地址找IP地址）
4. 数据链路层、物理层协议：CSMA/CD（**CSMA/CD** 是一种基于 **载波监听多路访问与碰撞检测** 的协议，常用于以太网（Ethernet）中。这种协议是最初的以太网标准（10BASE-T、100BASE-T）中使用的协议，旨在解决多台设备共享同一通信介质时的数据冲突问题。）、TokingRing（**Token Ring** 是一种通过 **令牌传递** 的方式来控制访问的协议，广泛应用于 IBM 的局域网系统中。它使用环形拓扑结构（每个设备都连接到环中）来确保数据的有序传输。）
