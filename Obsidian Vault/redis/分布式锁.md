# 为什么 Redis 锁不能替代唯一索引

这是最关键的。

很多人误以为：

```
我已经加 Redis 锁了就不会重复了
```

实际上不是。

因为 Redis 锁会失效。

例如：

---

## 场景 1：锁过期

线程 A：

```
获得锁（10 秒）
```

结果：

```
GC 卡顿 15 秒
```

锁自动过期。

这时线程 B：

```
重新获得锁
```

于是：

```
A 和 B 同时执行
```

最终：

```
插入两条重复数据
```

---

## 场景 2：Redis 主从切换

A 获取锁：

```
写入 master
```

但：

```
master 还没同步 slave
```

master 挂了。

slave 晋升。

B 又获取到同一个锁。

于是：

```
双持锁
```

---

## 场景 3：业务代码异常

即使锁没问题：

```
代码逻辑仍可能重复 insert
```

例如：

```
if notExists {    insert()}
```

两个线程同时通过检查。

仍然重复。
